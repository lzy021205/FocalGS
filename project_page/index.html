FocalGS: Adaptive Focal 3D Gaussian Splatting for Continuous Zoom Rendering

Zeyu Liu · Chao Wang · Jiahao Wu · Jie Liang · Ronggang Wang

Paper DOI Code Dataset Release Held Video

FocalGS learns a unified focal-adaptive 3D Gaussian representation from multi-view, multi-focal observations, enabling continuous viewpoint and zoom synthesis.

Abstract

Images captured with different focal lengths exhibit coupled changes in field of view, perspective, and defocus blur. FocalGS reconstructs a unified 3D representation from multi-view images captured under varying focal lengths, supporting both free-viewpoint synthesis and smooth continuous zoom control.

The method builds on 3D Gaussian Splatting with a focal-aware representation that separates focal-invariant structure from scale-dependent residual variation. A physical thin-lens defocus model is incorporated during rendering, helping prevent defocus blur from being absorbed into scene geometry and improving recovery of sharp details.

Method

A focal-adaptive Gaussian representation for zoom-aware rendering.

FocalGS keeps a static intrinsic anchor feature and predicts a focal-conditioned residual feature using a multi-resolution hash field.

A complementary adaptive gate fuses the static and focal-dependent features before Gaussian attribute decoding.

Parallel Gaussian decoders predict offsets, opacity, color, scaling, and rotation for neural Gaussians anchored in 3D.

A thin-lens Circle of Confusion model supports physical defocus supervision and controllable depth-of-field rendering.
